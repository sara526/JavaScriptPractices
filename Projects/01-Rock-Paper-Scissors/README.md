# 🪨 Rock Paper Scissors Game

A simple JavaScript project built while practicing core JavaScript concepts.

## 🚀 Features

* User chooses **Rock**, **Paper**, or **Scissors**.
* Computer generates a random choice.
* Determines the winner based on the game rules.
* Validates user input.
* Allows the user to play multiple rounds.

## 🛠️ Concepts Practiced

* Variables (`const`)
* Functions
* Arrays
* Array Methods (`includes`)
* Conditional Statements (`if`, `else if`, `else`)
* Logical Operators (`&&`, `||`, `!`)
* `Math.random()`
* `Math.floor()`
* String Method (`toLowerCase()`)
* Input Validation
* Function Calls & Recursion (Play Again)

## ▶️ How to Run

1. Open `index.html` in your browser.
2. Enter one of the following choices:

   * `rock`
   * `paper`
   * `scissors`
3. View the result in the browser console.
4. Choose whether to play another round.

## 📚 Learning Goal

This project was created to reinforce JavaScript fundamentals by combining multiple concepts into one practical application instead of solving isolated exercises.
